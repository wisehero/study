# 공부 목표: 카테고리와 상품 연결

> 상태: 시작 전 · 작성일: 2026-09-09 · 상위 주제: 전시 도메인

## 학습 목적

상품을 탐색하기 위한 카테고리 계층과 상품 연결을 모델링하고, 구조 변경 후에도 탐색 결과와 데이터가 일관되도록 한다.

## 핵심 개념별 목표

- [ ] 카테고리는 상품을 묶는 탐색 단위다. 상위·하위 카테고리와 같은 부모 아래의 표시 순서를 구분한다.
- [ ] 상품과 카테고리의 연결은 상품 자체와 별개다. 한 상품의 여러 카테고리 소속 여부와 카테고리별 진열 순서를 정책으로 정한다.
- [ ] 순환 참조는 자신의 하위 카테고리를 부모로 지정하는 등 계층이 고리를 이루는 상태다. 단일 요청 검증과 동시 구조 변경 시 검증을 구분한다.
- [ ] 하위 카테고리가 있는 항목의 삭제, 상품이 연결된 항목의 삭제, 비활성 상위 항목 아래의 노출 규칙을 명시한다.

## 초기 실습 정책

다음은 연습을 구체화하기 위해 선택한 정책이다. 실제 회사의 현재 동작이나 모든 쇼핑몰의 공통 규칙을 뜻하지 않는다. 정책을 바꾸면 이유와 영향받는 테스트를 함께 기록한다.

- 초기 실습은 카테고리당 부모가 최대 하나인 트리 구조로 시작한다. 자신과 자신의 하위 항목을 부모로 지정할 수 없다.
- 한 상품은 여러 카테고리에 연결할 수 있지만, 동일 카테고리와 상품의 연결은 중복될 수 없다.
- 하위 항목 또는 상품 연결이 남은 카테고리의 삭제는 거절한다. 이동·연결 해제 뒤 삭제하는 명시적인 절차를 사용한다.
- 상위 카테고리가 비활성이면 고객 탐색 경로에서 그 하위도 숨긴다. 상품 상세의 직접 접근 정책은 상품 공개 정책으로 별도 판단한다.

## 실습 과제

1. 카테고리 생성·이동·비활성화와 상품 연결 기능을 설계하고 계층 조회 결과를 작성한다.
2. 자기 자신을 부모로 지정하거나 자손 아래로 이동하는 요청을 거절하는지 검증한다.
3. 카테고리 A와 B를 동시에 서로의 하위로 이동하는 상황을 재현하고, 계층 변경의 잠금 또는 버전 검증 범위를 결정한다.
4. 카테고리 이동 전후의 트리 조회 SQL과 상품 목록 결과를 확인한다.

## 스스로 설명할 질문

- 상품의 소속 카테고리와 전시 화면의 구역은 왜 다른 개념인가?
- 동시에 들어온 두 요청이 각각 검증을 통과해도 순환이 생길 수 있는가?
- 상위 카테고리 비활성화는 하위 탐색과 상품 상세에 각각 어떤 영향을 주는가?

## 완료 기준

- [ ] 계층과 상품 연결에 대한 데이터 모델·제약을 설명한다.
- [ ] 중복 연결, 순환, 삭제 조건을 테스트로 검증한다.
- [ ] 동시 계층 변경에서도 규칙이 유지됨을 실제 DB로 확인한다.
- [ ] 설계 이유, 실패 또는 경계 조건, 검증 결과를 학습 노트와 실습 기록에 남긴다.
