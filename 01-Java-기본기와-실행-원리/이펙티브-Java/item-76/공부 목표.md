# 아이템 76: 실패 이후에도 일관된 상태 유지

> 상태: 시작 전 · 선정 순서: 18/30 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

작업이 실패했을 때 객체의 상태가 일부만 변경되지 않도록 설계한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

기간의 시작을 먼저 변경하고 종료 검증에서 실패하는 예제를 만든다. 사전 검증 또는 새 값 생성 후 교체로 개선한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

DB 롤백이 일반 Java 객체의 필드까지 자동으로 복원하는 것은 아니다. 외부 호출의 효과도 따로 검토한다.
