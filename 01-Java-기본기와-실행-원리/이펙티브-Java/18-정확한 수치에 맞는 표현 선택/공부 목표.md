## 실습 과제

정수 원화 계산과 소수 할인 계산을 long·double·BigDecimal로 비교한다. 문자열과 double로 생성한 BigDecimal의 차이를 확인한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

BigDecimal도 반올림과 비교 기준을 정해야 한다. long을 사용하면 범위와 연산 중 오버플로 가능성을 확인한다.
