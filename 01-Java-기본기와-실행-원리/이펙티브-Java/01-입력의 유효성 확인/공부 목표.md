# 아이템 49: 입력의 유효성 확인

> 상태: 검증 중 · 학습 순서: 01/30 · 난이도: 기초 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

잘못된 입력이 내부 상태를 변경하기 전에 명확하게 거절되도록 한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

가격·노출 기간·페이지 크기에 경계값을 넣고 HTTP 요청 검증과 순수 Java 업무 검증의 책임을 나눈다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. Java Lab 실습 코드와 테스트는 구현했으며, 검증 결과는 아래 실습 기록에서 확인한다. 학습 완료 처리는 아직 하지 않았다.

## 적용할 때 확인할 점

컨트롤러 검증만 있으면 다른 호출 경로에서 우회될 수 있다. 어떤 계층이 어떤 규칙을 보장하는지 적는다.
