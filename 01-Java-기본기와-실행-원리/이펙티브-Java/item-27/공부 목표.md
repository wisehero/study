# 아이템 27: 비검사 경고의 원인 제거

> 상태: 시작 전 · 선정 순서: 23/30 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

타입 안전성을 확인할 수 없다는 경고를 추적하고 검증한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

로 타입과 형변환이 섞인 예제를 javac 경고와 함께 확인한 뒤 제네릭으로 개선한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

경고 억제가 필요하면 안전하다는 근거를 설명하고 가장 작은 범위에 적용한다. 경고를 숨긴 것을 해결로 기록하지 않는다.
