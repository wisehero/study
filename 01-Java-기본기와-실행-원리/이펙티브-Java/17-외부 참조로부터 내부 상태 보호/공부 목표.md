# 아이템 50: 외부 참조로부터 내부 상태 보호

> 상태: 학습 중 · 학습 순서: 17/30 · 난이도: 중급 · 기준: Effective Java 3판 · 작성일: 2026-09-10 · 학습일: 2026-09-19

## 학습 목적과 기억할 기준

가변 입력과 반환값을 통해 객체 내부 상태가 바뀌는 경로를 확인한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

진열 상품 목록을 생성자에 전달한 뒤 원본 목록을 변경한다. 반환 목록과 그 안의 가변 원소도 각각 변경해 본다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

읽기 전용 뷰, 얕은 복사, 깊은 복사는 보장 범위가 다르다. 필요 이상으로 모든 객체를 복사하지 않는다.

## 완료 기준

- [ ] 원칙이 해결하는 문제와 적용 범위를 자신의 말로 설명한다.
- [ ] 위 실습의 예상 결과와 실제 결과를 비교하고 실패 또는 경계 사례를 남긴다.
- [ ] 개선 방법과 대안의 비용을 설명하고 코드·테스트·측정 결과를 연결한다.

## 학습 기록

- 학습 노트: [방어적 복사와 참조 관계 그림](학습%20노트.md) — 객체 수정과 목록 교체, String 불변성, 입력·출력 복사, 읽기 전용 뷰를 SVG 다섯 장으로 정리했다. 복사 후 검증하는 순서와 복사 범위 판단 기준도 포함한다.
- 실습 코드와 환경: 학습 노트에 설명용 Java 코드를 기록했다. Java Lab 실행 실습은 아직 추가하지 않았다.

- 남은 질문: 입력에서만 복사한 경우와 입력·출력 모두 복사한 경우의 변경 영향을 직접 실행해 비교한다.
