검증일: 2026-09-11 · 환경: Java 21 toolchain · Gradle Wrapper · JUnit

## 문제와 개선

빈 목록과 값이 있는 목록 모두 수정 가능하고 원본 목록과 분리되는지 확인했다. 수정 불가능한 스냅샷, 가변 원소 공유, 조회 예외 전파, 존재하지 않는 카테고리 구분, 원본의 null 반환을 오류로 처리하는 동작도 확인했다.

## 결과

이 항목의 테스트 6개가 통과했다. 전체 테스트는 기존 컬렉션 3개를 포함해 13개가 통과했다. 예상한 예외와 상태 유지·반환 계약을 assertion으로 확인했다.

실행 예제에서도 음수 가격 변경 실패 후 가격 1000 유지, 빈 결과 [], 빈 목록에 상품 추가 후 크기 1, 원본 재조회 크기 0을 확인했다.

## 범위와 남은 확인

순수 Java에서 수행한 검증이다. DB 연결 실패는 실제 DB 대신 예외를 던지는 조회 구현으로 모의했다. HTTP 검증과 업무 검증의 계층별 연동, DB·트랜잭션 동작은 아직 검증하지 않았다. 동시 접근과 깊은 복사도 이 실습의 보장 범위가 아니다. 직접 코드를 변경하고 결과를 설명하는 학습 확인이 남아 있어 상태는 검증 중으로 둔다.
