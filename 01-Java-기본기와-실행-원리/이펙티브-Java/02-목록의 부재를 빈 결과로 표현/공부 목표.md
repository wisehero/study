# 아이템 54: 목록의 부재를 빈 결과로 표현

> 상태: 검증 중 · 학습 순서: 02/30 · 난이도: 기초 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

정상적인 목록 조회에서 항목이 없는 결과를 일관되게 반환한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

카테고리 상품이 없을 때 빈 목록을 반환하고 호출자가 별도의 null 분기 없이 처리하도록 만든다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. Java Lab 실습 코드와 테스트는 구현했으며, 검증 결과는 아래 실습 기록에서 확인한다. 학습 완료 처리는 아직 하지 않았다.

## 적용할 때 확인할 점

조회 실패를 빈 목록으로 숨기지 않는다. 정상적인 결과 없음과 시스템 오류는 별도로 표현한다.

- [ ] 원칙이 해결하는 문제와 적용 범위를 자신의 말로 설명한다.
- [ ] 위 실습의 예상 결과와 실제 결과를 비교하고 실패 또는 경계 사례를 남긴다.
- [ ] 개선 방법과 대안의 비용을 설명하고 코드·테스트·측정 결과를 연결한다.
