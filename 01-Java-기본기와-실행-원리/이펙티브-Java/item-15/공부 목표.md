# 아이템 15: 외부에 공개하는 범위 제한

> 상태: 시작 전 · 선정 순서: 7/30 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

외부에서 접근할 수 있는 구현과 상태 변경 경로를 필요한 만큼만 제공한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

상품 모델의 필드·생성자·상태 변경 메서드의 접근 범위를 줄이고 외부 코드에서 가능한 조작을 비교한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

public setter를 제거한 것만으로 규칙이 보호되지는 않는다. 반환한 가변 객체를 통한 변경도 점검한다.
