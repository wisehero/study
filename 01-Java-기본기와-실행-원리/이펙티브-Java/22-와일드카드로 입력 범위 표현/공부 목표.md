# 아이템 31: 와일드카드로 입력 범위 표현

> 상태: 시작 전 · 학습 순서: 22/30 · 난이도: 중급 심화 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

값을 제공하는 쪽과 값을 받아들이는 쪽을 구분해 제네릭 계약을 설계한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

컬렉션 복사 메서드의 원본 목록을 ? extends T, 값을 넣을 대상 목록을 ? super T로 표현하고 상위·하위 타입 목록의 전달 가능 여부를 확인한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

PECS는 T를 제공하면 extends, T를 받아들이면 super를 검토하는 기준이다. 제공과 수용을 동시에 요구하면 단순 적용하지 않는다.
