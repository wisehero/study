# 아이템 20: 역할을 인터페이스로 정의

> 상태: 시작 전 · 선정 순서: 22/30 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

외부에 제공할 역할과 구현을 공유하기 위한 구조를 구분한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

할인 정책 두 가지를 인터페이스로 정의하고 호출자가 같은 계약으로 사용하는지 확인한다. 추상 클래스 방식과 비교한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

구현체가 하나인 모든 클래스에 인터페이스를 만들 필요는 없다. 확장 지점과 교체 필요를 근거로 선택한다.
