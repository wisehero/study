# 아이템 26: 제네릭 타입 명시

> 상태: 시작 전 · 선정 순서: 10/30 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

컬렉션에 담기는 타입을 컴파일 시점에 검사할 수 있도록 표현한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

로 타입 List에 서로 다른 값을 넣는 예제를 List<ProductCode>로 바꾸고 오류가 발견되는 시점을 비교한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

List<Object>와 로 타입 List는 같은 의미가 아니다. 필요한 타입을 모를 때는 List<?>의 사용 조건도 확인한다.
