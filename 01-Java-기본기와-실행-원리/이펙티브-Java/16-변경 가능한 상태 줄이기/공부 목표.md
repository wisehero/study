# 아이템 17: 변경 가능한 상태 줄이기

> 상태: 검증 중 · 학습 순서: 16/30 · 난이도: 중급 · 기준: Effective Java 3판 · 작성일: 2026-09-10 · 학습일: 2026-09-15

## 학습 목적과 기억할 기준

객체의 상태가 언제 누구에 의해 바뀔 수 있는지 제한한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

가격을 불변 객체로 만들고 할인 시 새 객체를 반환한다. 가변 목록을 필드로 가진 record, List.copyOf, 가변 원소 복사를 그림과 테스트로 비교한다. 최초 노출 기간 과제는 대화에서 다룬 가격 예제로 조정했다.

순수 Java 예제와 테스트로 확인했다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 직접 코드 변경 후 결과를 설명하는 학습 확인이 남아 있어 완료 처리하지 않았다.

## 적용할 때 확인할 점

final과 record는 참조 대상까지 깊게 불변으로 만들지 않는다. JPA 엔티티 등 가변성이 필요한 대상과 구분한다.

## 완료 기준

- [ ] 원칙이 해결하는 문제와 적용 범위를 자신의 말로 설명한다.
- [ ] 위 실습의 예상 결과와 실제 결과를 비교하고 실패 또는 경계 사례를 남긴다.
- [ ] 개선 방법과 대안의 비용을 설명하고 코드·테스트·측정 결과를 연결한다.
