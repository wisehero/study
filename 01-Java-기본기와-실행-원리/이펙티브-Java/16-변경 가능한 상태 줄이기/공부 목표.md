# 아이템 17: 변경 가능한 상태 줄이기

> 상태: 시작 전 · 학습 순서: 16/30 · 난이도: 중급 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

객체의 상태가 언제 누구에 의해 바뀔 수 있는지 제한한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

노출 기간을 불변 값 객체로 만들고 기간 변경 시 새 객체를 반환한다. 가변 목록을 필드로 가진 record도 비교한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

final과 record는 참조 대상까지 깊게 불변으로 만들지 않는다. JPA 엔티티 등 가변성이 필요한 대상과 구분한다.
