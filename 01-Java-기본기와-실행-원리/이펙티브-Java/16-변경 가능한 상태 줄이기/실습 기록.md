# 불변 객체 실습 기록

검증일: 2026-09-15 · Java 21 toolchain · Gradle Wrapper · JUnit

## 목적과 읽는 순서

대화의 가격·태그 예제로 불변 객체와 참조 공유를 확인한다. 공부 목표에 처음 적었던 노출 기간 대신 같은 원리를 더 짧게 드러내는 가격 예제를 사용한다. 노출 기간의 날짜 검증은 이번 범위에 포함하지 않는다.

1. [Price](../../../java-lab/src/main/java/dev/study/javalab/effectiveJava/chapter16/Price.java): 할인 결과를 새 객체로 반환한다.
2. [Product](../../../java-lab/src/main/java/dev/study/javalab/effectiveJava/chapter16/Product.java): String 태그 목록을 수정 불가능한 복사본으로 보관한다.
3. [ImmutableExampleTest](../../../java-lab/src/test/java/dev/study/javalab/effectiveJava/chapter16/ImmutableExampleTest.java): 가격 변경과 실패, 입력·출력 보호, 그림의 세 참조 구조를 검증한다.

다른 chapter의 Product와 독립된 예제다. Tag와 Tags record는 문제를 재현하는 테스트 전용 타입이며 운영용 불변 Product에 가변 원소를 도입하지 않는다.

## 테스트 결과

Java Lab에서 `./gradlew test`를 실행했다. 신규 7개를 포함한 전체 54개 테스트가 통과했으며 실패·오류·건너뜀은 없었다.

| 확인한 내용 | 실제 결과 |
| --- | --- |
| 10,000원에서 1,000원 할인 | 새 객체는 9,000원, 기존 객체는 10,000원이다. |
| 0원·0원 할인·전액 할인 | 허용하며 결과가 각각 지정한 경계값을 따른다. |
| 음수 가격·음수 할인·가격 초과 할인 | IllegalArgumentException이 발생하고 기존 가격은 유지된다. |
| 외부 String 목록의 교체·추가·삭제 | Product의 태그는 처음 값 그대로다. |
| getter 목록의 추가·교체·삭제 | UnsupportedOperationException이 발생한다. |
| 빈 목록·null 입력 | 빈 목록은 허용하며 null 목록·null 원소는 거절한다. |
| 그림 1: 가변 목록을 보유한 record | 원본과 같은 목록을 참조한다. 외부 원소 변경과 목록 삭제가 모두 반영된다. |
| 그림 2: List.copyOf와 가변 Tag | 목록은 분리되지만 원소는 같다. 외부 목록을 비워도 복사본에 원소가 남으며 Tag 이름 변경은 공유된다. |
| 그림 3: Tag도 새로 생성 | 외부 원소와 분리된다. 다만 복사본의 Tag를 직접 받으면 여전히 수정할 수 있다. |

## 그림과 실행

[학습 노트](학습%20노트.md)에 PNG 세 장을 삽입했다. images 폴더에 같은 그림의 SVG와 외부 파일 의존성이 없는 HTML을 보관한다. HTML은 앞서 브라우저에서 세 단계 전환·이름 변경·초기화를 확인한 자료를 그대로 복사했다. 이번에는 원본과 복사본 파일의 일치 및 문서 링크를 확인했다.

Java Lab 디렉터리에서 이번 실습만 실행할 수 있다.

```sh
./gradlew test --tests 'dev.study.javalab.effectiveJava.chapter16.*'
```

별도 main과 빌드 설정은 추가하지 않았다. 불변성의 효과와 실패 양상을 검증하는 실습이며, 객체 할당 비용이나 복사 성능을 측정한 결과는 아니다. 직접 final이나 copyOf를 바꿔 어느 검증이 실패하는지 설명하는 학습 확인은 남아 있다.
