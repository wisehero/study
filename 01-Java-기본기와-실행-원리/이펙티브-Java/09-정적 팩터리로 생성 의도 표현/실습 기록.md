## 검증 결과와 범위

`./gradlew test`로 신규 3개와 이 브랜치의 기존 25개, 전체 28개 테스트가 통과했다. 다른 미병합 PR의 실습은 이 브랜치에 포함하지 않았다.

- ready와 onSale이 같은 상품명·가격을 받아 서로 다른 상태를 만드는지 확인했다.
- 두 팩터리 모두 null·빈 상품명·공백·음수 가격을 거절하고 0원은 허용한다.
- Boolean.valueOf가 기존 TRUE/FALSE를 재사용하는 사례를 확인했다.

상품 예제는 매번 새 객체를 만들며 공통 private 생성자에서 검증한다. 기존 목표의 기획전 사례 대신 대화의 상품 사례로 구현했다. 구현체 선택은 개념 노트에 남기고 실습에서 별도의 클래스 계층을 늘리지 않았다.

소스 한 파일과 테스트 한 파일로 핵심만 구성했다. 별도 main은 추가하지 않았으며 테스트를 순서대로 읽으면 된다. 직접 코드를 변경하고 결과를 설명하는 학습 확인은 남아 있다.
