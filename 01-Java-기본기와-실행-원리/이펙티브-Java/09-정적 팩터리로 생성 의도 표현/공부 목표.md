# 아이템 1: 정적 팩터리로 생성 의도 표현

> 상태: 학습 중 · 학습 순서: 09/30 · 난이도: 기초 응용 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

생성 메서드의 이름과 반환 계약으로 객체를 만드는 목적을 표현한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

기획전 초안 생성과 기존 데이터 복원을 생성자 또는 이름 있는 생성 메서드로 각각 표현하고 호출부의 의미를 비교한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

단순한 객체는 생성자만으로 충분할 수 있다. 정적 팩터리 자체가 상태 검증이나 불변성을 보장하지는 않는다.

## 완료 기준

- [ ] 원칙이 해결하는 문제와 적용 범위를 자신의 말로 설명한다.
