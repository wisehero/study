# 아이템 5: 필요한 자원을 외부에서 전달

> 상태: 시작 전 · 선정 순서: 3/30 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

객체가 필요한 자원을 전달받게 하여 실행 환경을 바꾸며 테스트한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

기획전 노출 판단에 Clock을 전달하고 고정된 시각으로 시작 직전·종료 시각의 결과를 검증한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

의존성 주입은 순수 Java 생성자로도 할 수 있다. 모든 클래스를 Spring 빈으로 만드는 규칙은 아니다.

## 완료 기준

- [ ] 원칙이 해결하는 문제와 적용 범위를 자신의 말로 설명한다.
- [ ] 위 실습의 예상 결과와 실제 결과를 비교하고 실패 또는 경계 사례를 남긴다.
- [ ] 개선 방법과 대안의 비용을 설명하고 코드·테스트·측정 결과를 연결한다.
