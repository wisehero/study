# 아이템 61: 기본형과 박싱 타입의 의미 구분

> 상태: 시작 전 · 학습 순서: 03/30 · 난이도: 기초 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

값 자체를 다루는 경우와 값의 부재가 필요한 경우를 구분한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

누락된 수량과 수량 0을 Long 요청 필드로 구분하고 null의 자동 언박싱 오류를 재현한다. 값 비교와 참조 비교도 확인한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

입력 누락이나 아직 생성되지 않은 ID를 표현할 때 박싱 타입이 필요할 수 있다. 제네릭에도 참조 타입을 사용한다.
