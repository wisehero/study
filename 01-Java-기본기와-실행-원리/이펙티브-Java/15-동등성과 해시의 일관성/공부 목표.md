# 아이템 11: 동등성과 해시의 일관성

> 상태: 시작 전 · 학습 순서: 15/30 · 난이도: 중급 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

equals로 같다고 판단한 객체는 동일한 해시값을 제공하도록 한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

같은 상품 코드로 HashMap에 저장·조회하고 HashSet에서 중복을 제거한다. 해시 키에 사용한 상태를 바꾼 경우도 재현한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

해시값이 같다고 객체가 반드시 같은 것은 아니다. 가변 필드를 키의 동등성 기준에 넣으면 조회가 깨질 수 있다.
