# 아이템 10: 객체 동등성의 기준

> 상태: 시작 전 · 학습 순서: 14/30 · 난이도: 중급 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

두 객체를 같은 값으로 판단하는 기준과 equals의 계약을 설명한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

기존 Java Lab의 ProductCode를 일반 클래스로 바꾸고, 같은 코드의 서로 다른 인스턴스가 동등하게 취급되도록 구현한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

값 객체와 영속성 엔티티의 동등성 기준은 다를 수 있다. 상속을 포함하면 대칭성과 추이성도 확인한다.
