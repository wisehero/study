# 아이템 9: 예외에도 자원 해제

> 상태: 시작 전 · 학습 순서: 08/30 · 난이도: 기초 응용 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

직접 연 파일과 스트림의 해제 책임을 명확히 한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

파일 읽기 도중 예외를 발생시키고 try-with-resources에서 close 호출을 확인한다. 작업과 close가 모두 실패한 경우도 관찰한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

다른 계층이나 프레임워크가 소유하는 자원을 임의로 닫지 않는다. 자원 소유권을 먼저 확인한다.
