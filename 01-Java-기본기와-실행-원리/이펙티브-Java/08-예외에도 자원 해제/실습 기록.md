## 검증 결과와 범위

`./gradlew test`로 신규 3개와 이 브랜치의 기존 25개, 전체 28개 테스트가 통과했다. 다른 미병합 PR의 실습은 이 브랜치에 포함하지 않았다.

- 정상 작업 뒤에도 close가 호출된다.
- 작업과 close가 모두 실패하면 작업 예외를 그대로 전달하고 close 예외를 getSuppressed로 확인할 수 있다.
- 반환값을 구했더라도 close가 실패하면 값 대신 예외가 전달된다.

실제 파일 대신 작은 AutoCloseable 자원으로 동작을 모의한다. 여러 자원의 역순 해제와 생성 도중 실패, 실제 파일 읽기는 개념 노트의 후속 확인 범위로 남겼다.

소스 한 파일과 테스트 한 파일로 핵심만 구성했다. 별도 main은 추가하지 않았으며 테스트를 순서대로 읽으면 된다. 직접 코드를 변경하고 결과를 설명하는 학습 확인은 남아 있다.
