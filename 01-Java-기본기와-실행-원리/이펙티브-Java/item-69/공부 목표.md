# 아이템 69: 정상 분기와 예외 구분

## 학습 목적과 기억할 기준

예상된 제어 흐름과 실패 처리를 구분한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

목록 탐색 종료나 단순 조회 부재를 예외로 처리하는 코드와 명시적 조건으로 처리하는 코드를 비교한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

업무상 예상할 수 있는 오류라는 이유만으로 예외 사용이 항상 부적절한 것은 아니다. 호출 계약을 기준으로 판단한다.
