# 이펙티브 Java: 우선 학습할 30선

작성일: 2026-09-10 · 기준: Joshua Bloch, Effective Java 3판

## 목적과 선정 기준

3년차 Java·Spring 개발자가 코드 작성·리뷰·장애 분석에서 활용할 원칙 30개를 정리한다. 앞선 대화에서 고른 20개와 추가 10개를 유지하되, 선행 개념의 양과 실습 난이도를 기준으로 기초에서 심화 순서로 재배치했다. 공식 30선이나 책에서 정한 난이도 순위는 아니며, Java·Spring 개발자를 위한 권장 학습 순서다.

목표는 규칙을 외우는 것이 아니라 적용 이유, 예외와 비용을 설명하고 잘못 적용했을 때의 문제를 재현하는 것이다. 각 제목·설명·실습은 우리 학습을 위해 작성했으며 책 본문을 대체하는 요약은 아니다. 새 코드 구현과 학습 완료 처리는 포함하지 않았다.

## 단계별로 익힐 내용

1. **01~06 · 기초:** 입력 검증, 빈 결과, 기본형, enum, 접근 범위와 예외를 삼키지 않는 습관을 익힌다. 작은 메서드 하나에서 결과를 확인하는 단계다.
2. **07~12 · 기초 응용:** 정상 분기와 예외, 자원 해제, 객체 생성 방식, 의존성 주입과 인터페이스를 익힌다. 호출자와 객체의 책임을 구분한다.
3. **13~18 · 중급:** 조합, 동등성·해시, 불변성·방어적 복사, 정확한 금액 계산을 다룬다. 여러 객체와 컬렉션에 걸친 계약과 경계 조건을 검증한다.
4. **19~24 · 중급 심화:** 제네릭, Optional, 비검사 경고, 와일드카드, Stream과 계층에 맞는 예외를 연결한다. 타입과 호출 계약을 설계하는 단계다.
5. **25~30 · 심화:** 실패 이후 상태, 객체 참조 수명, 공유 상태, 실행기, 병렬 처리와 성능 측정을 다룬다. 실행 시점과 환경에 따라 달라지는 문제를 재현하고 검증한다.

현재 Java Lab의 컬렉션 예제는 14~15번(책의 아이템 10·11)을 실습할 때 활용한다. 새로 시작할 때는 01번부터 진행하고, 기존 예제를 먼저 읽고 싶다면 필요한 기초 개념을 확인하며 해당 구간으로 이동할 수 있다.

## 서로 연결해 볼 기준

- equals와 hashCode는 함께 확인하고, 해시 컬렉션에 넣은 뒤 기준 필드를 변경하는 경우도 다룬다.
- final·record·복사의 보장 범위를 구분한다. 내부에 가변 객체가 있으면 별도 확인이 필요하다.
- Optional과 빈 목록은 각각 단일 결과 부재와 정상적인 목록의 결과 없음을 표현한다. 시스템 실패와 혼동하지 않는다.
- 실패 원자성은 객체의 상태에 대한 성질이다. DB 롤백과 외부 시스템의 효과까지 동일하게 보장되는 것은 아니다.
- 공유 데이터 보호와 작업 실행 정책을 구분한다. 실행기나 병렬 Stream을 사용하는 것만으로 업무 데이터가 안전해지지 않는다.
- 금액의 단위·소수점·반올림과 입력 누락의 의미를 정한 뒤 수 타입을 선택한다.

- 각 `학습순서-아이템 이름` 폴더에 `공부 목표.md`를 두고, 학습하면서 노트와 실습 기록을 추가한다.
- 상태는 `시작 전 → 학습 중 → 검증 중 → 완료`로 관리하고 목록과 상세 문서를 함께 갱신한다.

- 항목을 추가할 때는 선행 지식과 실습 난이도를 보고 위치를 정한다. 순서가 바뀌면 폴더 번호·목록·상세 문서의 학습 순서를 함께 수정한다. 책의 아이템 번호는 유지하며, 변경된 경로를 참조하는 링크도 갱신한다.
