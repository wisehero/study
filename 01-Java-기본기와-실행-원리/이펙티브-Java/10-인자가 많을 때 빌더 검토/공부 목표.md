# 아이템 2: 인자가 많을 때 빌더 검토

> 상태: 검증 중 · 학습 순서: 10/30 · 난이도: 기초 응용 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

필수값과 선택값이 많은 객체를 어떤 방식으로 안전하게 조립할지 판단한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

기획전 생성 요청에 제목·기간·배너·옵션을 추가하고, 생성자와 빌더의 잘못된 조합 처리 및 호출 가독성을 비교한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 상품 예제로 짧은 실습과 테스트를 구현했다. 기획전·교차 필드 검증은 후속 범위이며 완료 처리는 하지 않았다.

## 적용할 때 확인할 점

필드가 적은 객체에도 빌더를 일괄 적용하지 않는다. 필수값 누락과 교차 필드 검증은 별도로 설계한다.
