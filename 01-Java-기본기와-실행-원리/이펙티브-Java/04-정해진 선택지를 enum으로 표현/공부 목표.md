# 아이템 34: 정해진 선택지를 enum으로 표현

> 상태: 검증 중 · 학습 순서: 04/30 · 난이도: 기초 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

허용되는 값의 집합과 그 값이 의미하는 상태를 타입으로 드러낸다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

대화에서 다룬 상품 상태를 enum으로 표현하고 잘못된 외부 코드·허용되지 않은 상태 전환을 검증한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 핵심만 보여주는 상품·상태 코드와 테스트를 구현했다. 학습 완료 처리는 아직 하지 않았다.

## 적용할 때 확인할 점

enum 선언만으로 상태 전환 규칙이 완성되지는 않는다. DB와 API에 노출할 표현도 별도로 정한다.
