# 접근 범위 실습 기록

검증일: 2026-09-11 · Java 21 toolchain · Gradle Wrapper · JUnit

## 읽는 순서

1. [Product](../../../java-lab/src/main/java/dev/study/javalab/effectiveJava/chapter05/Product.java): private 필드, 검증 후 변경, 목록 복사 반환을 읽는다.
2. [PriceValidator](../../../java-lab/src/main/java/dev/study/javalab/effectiveJava/chapter05/PriceValidator.java): package-private 보조 클래스와 메서드, private 생성자를 확인한다.
3. [AccessExampleTest](../../../java-lab/src/test/java/dev/study/javalab/effectiveJava/chapter05/AccessExampleTest.java): 가격 검증과 외부 목록 조작을 확인한다.

## 검증 결과

Java Lab에서 `./gradlew test`를 실행했다. 새 테스트 2개와 main 기준 기존 테스트 20개, 총 22개가 통과했다. 4번은 별도 미병합 PR이므로 이번 브랜치의 테스트 집계에 포함하지 않았다.

- 가격 -1로 변경하면 예외가 발생하고 기존 가격 1000을 유지한다. 0은 허용하며 음수 생성자 입력도 거절한다.
- 빈 목록에 직접 추가하거나 태그가 있는 반환 목록을 비우면 UnsupportedOperationException이 발생한다.
- null·공백 태그는 거절한다. 허용된 태그는 addTag로 추가한다.
- 먼저 받은 스냅샷은 이후 태그 추가의 영향을 받지 않는다. 내부 목록은 허용된 태그를 유지한다.

## 직접 해 볼 변경

테스트의 `product.price = -1` 주석을 해제하면 private 필드 접근으로 컴파일되지 않는다. 또한 tags()를 `return tags`로 바꾸면 반환 목록 보호 테스트가 실패한다. 이 두 변형은 이번 자동 검증에서는 실행하지 않았다.

## 범위와 비용

핵심만 보여주기 위해 소스 두 파일과 테스트 두 개로 구성했고 별도 main은 추가하지 않았다. 목록 복사 비용이 있지만 외부의 우회 변경과 이후 내부 변경으로부터 분리된다. String은 불변이지만 가변 원소까지 복사하는 방식은 아니다. 동시성, protected의 상세 규칙, 모듈 접근 제어는 이번 실습 범위가 아니다.
