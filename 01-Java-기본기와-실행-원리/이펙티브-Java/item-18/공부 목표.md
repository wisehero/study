# 아이템 18: 기능 확장에 조합 검토

> 상태: 시작 전 · 선정 순서: 9/30 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

다른 객체에 역할을 맡기는 구조와 상속으로 확장하는 구조를 비교한다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

할인 계산 기능에 로깅을 추가하는 예제를 상속과 위임으로 각각 구성하고 기존 구현 변경의 영향을 확인한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

상속이 항상 잘못된 것은 아니다. 의도된 확장 계약과 대체 가능성을 검토하고 선택 근거를 남긴다.
