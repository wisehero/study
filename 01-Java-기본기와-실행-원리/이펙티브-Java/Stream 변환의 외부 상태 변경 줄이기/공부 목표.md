# 아이템 46: Stream 변환의 외부 상태 변경 줄이기

> 상태: 시작 전 · 선정 순서: 12/30 · 기준: Effective Java 3판 · 작성일: 2026-09-10

## 학습 목적과 기억할 기준

변환과 집계의 결과가 입력과 연산으로 설명되도록 만든다.

이 문서는 책의 아이템을 바탕으로 정한 실습 목표다. 제목과 설명은 학습용 표현이며 책 본문의 인용이나 공식 중요도 순위를 뜻하지 않는다.

## 실습 과제

주문 목록을 처리하며 외부 Map을 수정하는 코드를 수집 연산으로 바꾸고 결과와 책임을 비교한다.

우선 순수 Java의 작은 예제로 원리를 확인한다. DB·HTTP·빈·트랜잭션이 필요한 부분은 Spring Lab에서 후속 실습한다. 이번 정리에서 새 실습 코드를 구현하거나 완료 처리하지 않았다.

## 적용할 때 확인할 점

단순한 반복문이 더 명료하면 사용할 수 있다. 외부 DB나 API 호출을 Stream 안에 숨기지 않는지 점검한다.
